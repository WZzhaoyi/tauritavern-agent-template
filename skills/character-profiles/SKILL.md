# Character Profiles

## 使用时机
- 角色首次在场景中出现时
- 需要确认角色外貌、性格或台词风格时
- 需要查阅角色背景故事时
- 不确定角色在当前情境下的典型反应时

## 注意事项
- 角色静态设定不包含阶段行为变化（阶段数据来自 `_stages` 文件和 `persist/` 状态值）。
- 当前角色关系状态（动态）从 `persist/` 获取，不从本 SKILL 获取。
- 详细角色档案放在 `references/` 子目录下，每角色一个文件，文件名与角色名对应。
