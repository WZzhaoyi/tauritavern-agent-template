# 《红楼梦》大观园示例

用于验证模板最小创作闭环：

- 四个地图地点：怡红院、潇湘馆、蘅芜苑、秋爽斋。
- 四名与地点直接对应的人物：贾宝玉、林黛玉、薛宝钗、贾探春。
- 五项基础行动：前往、拜访、交谈、观察、继续。
- 一个“亲疏”状态维度。
- 一个诗社前夕的开场和一份最小世界书。

本目录只维护作品配置与素材。通用 Skills、交互扩展和主题从仓库根目录继承。

## 生成可导入产物

在仓库根目录执行：

```bash
python scripts/generate.py projects/hongloumeng
```

结果位于 `projects/hongloumeng/output/agent/`。

先导入角色卡；导入生成的 `.ttskill` 时，把目标作用域设为该角色卡。不要安装到全局、预设或 Profile 作用域。
